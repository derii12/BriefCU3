Это клиентская часть приложения Brief.
Страницы в appslovo/appslovo

phonelog.xaml.cs - Страница ввода номера телефона:
Ввод номера телефона и перенаправление на страницу регистрации или подтверждения звонком, в зависимости от того, существует ли учетная запись или нет.

register.xaml.cs - страница регистрации:
Ввод никнема и кода приглашения. (При успехе перенаправение на страницу подтверждения звонком)

confirm.xaml.cs - страница подтверждения
Ввод последних 4х цифр входящего звонка в качестве подтверждения привязки к конкретному номеру телефона. После сразу генерируется публичный и секретный ключ для этого пользователя (для обмена постами и реакциями). При каждом новом логине предыдущий секретный ключ стирается, а публичный, харнящийся в базе данных, заменяется новым.

homepage.xaml.cs - основная страница приложения:

Отображение постов друзей(расшифровка их при помощи секретного ключа), публикация поста и его шифрование с помощью публичных ключей от друзей(для каждого свой зашифрованный текст), реакции, добавление/удаление/поиск друзей, изменение имени пользователя.

addreactionpopup.xaml.cs- страница для создания реакции на пост
На вход получает объект публикацию, вводится до 10 символов и реакция привязывается к посту(шифруется при помощи алгоритма сквозного шифрования, из-за чего ее видят только общие друзья)

reactionslist.xaml.cs - страница с постом и списком реакций на этот пост
ползователь может увидеть реакции, которые оставили его общие с автором поста друзья.


settings.xaml.cs - страница с кнопками: выйти из аккаунта, удалить аккаунт, информация о приложении и свзяь с разработчиком, инструкция по использованию виджета
widgettutorial.xaml.cs - страница с инструкцией по использованию виджета
welcome.xaml.cs - страница, всплывающая при первой регистрации, несколько слайдов с картким приветстсием и некоторыми функцциями приложения.
streakpopuppage.xaml.cs - страница с информацией о текущем стрике
popup2.xaml.cs - страница подтверждения удаления друга(друг не сможет видеть ваши посты)
popup1.xaml.cs - подтверждение выхода из учетной записи(стирается секретный и публичный ключ)
information.xaml.cs - страница информации о приложении
